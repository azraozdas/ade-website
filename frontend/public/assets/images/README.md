# ADE Website Assets

## Required Images

Place the following images in this directory:

### Logo
- `logo-ade.png` — ADE logo for header (recommended size: 150x60px)

### Hero
- `hero-model.png` — Hero section model image (recommended size: 800x1000px)

### Products
- `product-foundation.jpg` — Hydra Skin Tint SPF15 (FACE category)
- `product-face.jpg` — Velvet Compact Powder (FACE category)
- `product-lips.jpg` — Satin Rose Lipstick (LIPS category)

### Optional
- `newsletter-bg.jpg` — Newsletter/About hero background (if needed)

### Icons (SVG)
- `search.svg` — Search icon
- `user.svg` — User/account icon
- `bag.svg` — Shopping bag icon

---

**Note:** If actual images are not available, the application will display placeholder backgrounds. Replace these placeholders with real product photography for production use.

## Image Guidelines

- **Format:** JPG for photos, PNG for logos with transparency
- **Optimization:** Compress images for web (recommended < 200KB per image)
- **Dimensions:** Maintain aspect ratios specified above
- **Alt Text:** All images include descriptive alt attributes for accessibility
